# UI仕様書

## 概要

本文書では,艦これ工廠任務廃棄プランナーのユーザーインターフェースの詳細仕様を定義する.

## 全体レイアウト

### 画面構成

```text
┌─────────────────────────────────────────────────┐
│ Header                                          │
├─────────────────────────────────────────────────┤
│ Global Warning Banner (条件付き表示)           │
├─────────────────────────────────────────────────┤
│ Sticky Dashboard                                │
│ ┌─────────────────────────────────────────────┐ │
│ │ 廃棄リスト (横スクロール)                   │ │
│ └─────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────┤
│ Control Bar                                     │
│ [フィルタ] [装備追加] [任務追加]               │
├─────────────────────────────────────────────────┤
│                                                 │
│ Mission List (スクロール)                       │
│ ┌─────┐ ┌─────┐ ┌─────┐                        │
│ │任務1│ │任務2│ │任務3│ ...                    │
│ └─────┘ └─────┘ └─────┘                        │
│                                                 │
├─────────────────────────────────────────────────┤
│ Footer Area (折りたたみ可能)                   │
```

### レスポンシブ対応

| ブレークポイント | 画面幅      | レイアウト変更                       |
| :--------------- | :---------- | :----------------------------------- |
| Desktop          | 1024px以上  | 3カラム任務グリッド                  |
| Tablet           | 768〜1023px | 2カラム任務グリッド                  |
| Mobile           | 767px以下   | 1カラム任務リスト,フィルタ折りたたみ |

## Header

### 構成要素

```text
┌────────────────────────────────────────────┐
│ 🔧 艦これ 工廠任務廃棄プランナー    [≡]   │
└────────────────────────────────────────────┘
```

* アプリ名(左寄せ)
* 設定メニューボタン(右寄せ,ハンバーガーアイコン)

### 設定メニュー

#### トリガー

[≡]ボタンクリック

#### 表示方法

ドロップダウンメニュー(右上から展開)

#### メニュー項目

```text
┌──────────────────────┐
│ 📤 装備をエクスポート │
│ 📤 任務をエクスポート │
│ 📥 データをインポート │
├──────────────────────┤
│ ℹ️ About             │
└──────────────────────┘
```

* 装備をエクスポート: `user_equipments.json`をダウンロード
* 任務をエクスポート: `user_missions.json`をダウンロード
* データをインポート: ファイル選択ダイアログを開く
* About: アプリ情報モーダルを開く

#### 初回起動時の動作

1. アプリ起動時に`localStorage['ksp_about_shown']`をチェック
2. フラグがない場合: Aboutモーダルを自動表示

4. 2回目以降は自動表示せず,設定メニューからのみ開く

#### ボタン

* [閉じる]: モーダルを閉じる(初回時はフラグ保存)

## Global Warning Banner

### 位置

Headerの直下,Sticky Dashboardの上

### 表示条件

* ネットワークエラー発生時
* データ更新通知時
* LocalStorageデータ破損検出時（起動時バリデーション）
* 重大なバリデーションエラー時

#### スタイル

* Warning: 黄色背景,黒文字,⚠️アイコン
* Error: 赤色背景,白文字,❌アイコン
* Info: 青色背景,白文字,ℹ️アイコン

#### 構成

```text
┌─────────────────────────────────────────────────┐
│ ⚠️ メッセージ内容                [再試行] [×] │
└─────────────────────────────────────────────────┘
```

* アイコン(左)
* メッセージテキスト(中央)
* アクションボタン(右,オプション)
* 閉じるボタン(右端)

## Sticky Dashboard

### Sticky Dashboardの位置

Global Warning Bannerの下,画面上部に固定

### 機能

選択中の任務から計算された廃棄リストを表示

### 開閉機能

タイトルバーをクリックで展開/折りたたみ可能

### タイトルバー構成

```text
┌─────────────────────────────────────────────────┐
│ 🗑️ 本日の廃棄リスト  選択中: 3  [▲/▼]        │
└─────────────────────────────────────────────────┘
```

* 左: タイトル + アイコン
* 中央右: 選択中の任務数バッジ
* 右端: 開閉アイコン(▲展開中, ▼折りたたみ中)

**デフォルト状態**: 展開

### 廃棄リスト表示

#### 状態: 任務未選択択

```text
┌─────────────────────────────────────────────────┐
│                                                 │
│         📋 任務を選択してください               │
│                                                 │

```

##### 状態: 計算中(Loading)

```text
┌─────────────────────────────────────────────────┐
│                                                 │
│         ⏳ 計算中...                            │
│                                                 │
└─────────────────────────────────────────────────┘
```

##### 状態: 廃棄リスト表示

```text
┌─────────────────────────────────────────────────────────────────┐
│ ┌─────────────┐ ┌─────────────┐ ┌─────────────┐              │
│ │ 機銃        │ │ 小口径主砲  │ │ 12cm単装砲  │ → [スクロール]│
```

##### カード形式

* ヘッダー部(上段):
    * カテゴリ名(左,太字)
    * 合計数バッジ(右,暗い背景)
* 内訳リスト(下段):
    * Item装備: 装備名 + 必要数
    * Category残数: 「何でもOK」+ 必要数(黄色背景)
* 背景色: 淡いグレー
* 境界線: 明確な罫線

##### 横スクロール

* デフォルトで3〜4件表示
* それ以上は横スクロール(snap-scroll)
* スクロールバー表示

##### ソート

* カテゴリ名のアルファベット順

## Control Bar

### Control Barの位置

Sticky Dashboardの下

### Control Barの構成

```text
┌────────────────────────────────────────────────────────────────────────────────┐
│ 🔍 [任務名検索...] [周期 ▼] [装備カテゴリ ▼]  [+ 装備管理] [+ 任務追加] │
└────────────────────────────────────────────────────────────────────────────────┘
```

### フィルタ

フィルタは組み合わせて使用可能(AND条件):

* テキスト検索 AND 周期 AND 装備カテゴリ
* 例: 「Weekly」かつ「機銃」を要求する任務のみ表示

#### フィルタ詳細

##### テキスト検索

* 入力フィールド: 任務名で部分一致検索
* プレースホルダー: `任務名を検索...`
* リアルタイム検索(デバウンス300ms)
* 左側に虫眼鏡アイコン

##### 周期フィルタ

###### 周期フィルタのトリガー

[周期 ▼]プルダウン選択

###### 周期フィルタの表示方法

ドロップダウン選択

###### 周期フィルタ項目

```text
┌────────────────────┐
│ 全て              │
│ Daily            │
│ Weekly           │
│ Monthly          │
│ Quarterly        │
│ Yearly           │
│ OneTime          │
└────────────────────┘
```

* デフォルト: `全て`
* 単一選択(ドロップダウン)
* 選択時: その周期の任務のみ表示
* SessionStorageに保存: `ksp_filter_period`

##### 装備カテゴリフィルタ

###### 装備カテゴリフィルタのトリガー

[装備カテゴリ ▼]プルダウン選択

###### 装備カテゴリフィルタの表示方法

ドロップダウン選択

###### フィルタ項目

```text
┌────────────────────┐
│ 全種別             │
│ 小口径主砲         │
│ 機銃               │
│ 魚雷               │
│ ...                │
└────────────────────┘
```

* デフォルト: `全種別`
* 動的生成: 装備マスタから一意なカテゴリを抽出
* 単一選択(ドロップダウン)
* 選択時: そのカテゴリを要求する任務のみ表示
* SessionStorageに保存: `ksp_filter_category`

##### フィルタの組み合わせ

###### AND条件

* テキスト検索 AND 周期フィルタ AND 装備カテゴリフィルタ
* 例1: テキスト「装備」+ 周期「Weekly」→ 任務名に「装備」を含むWeekly任務のみ
* 例2: 周期「Weekly」+ 装備「機銃」→ 機銃を要求するWeekly任務のみ
* 例3: 全てのフィルタを組み合わせ可能

###### OR条件

* 初期リリースでは未対応
* 将来的にチェックボックス形式で複数選択(OR条件)を検討

## Mission List

### Mission Listの位置

Control Barの下,画面中央メインエリア

### レイアウト

グリッドまたはリスト形式

### 任務一覧の開閉機能

任務一覧が長くなった場合にエラーログなど下部コンテンツへのアクセスを容易にするため,任務一覧エリア全体を折りたたみ可能にする.

#### トグル動作

* タイトルバーまたは専用ボタンをクリックで展開/折りたたみ
* 折りたたみ時: 任務カードを非表示にし,タイトルバーのみ表示
* 展開時: すべての任務カードを表示(デフォルト状態)

#### UI表示

```text
展開時:
┌─────────────────────────────────────────────────┐
│ 📋 任務一覧 (15件)                     [▲]     │
├─────────────────────────────────────────────────┤
│ [任務カード1]                                   │
│ [任務カード2]                                   │
│ ...                                             │
└─────────────────────────────────────────────────┘

折りたたみ時:
┌─────────────────────────────────────────────────┐
│ 📋 任務一覧 (15件)                     [▼]     │
└─────────────────────────────────────────────────┘
```

* タイトルバー左: アイコン + 「任務一覧」+ 件数表示
* タイトルバー右: 開閉アイコン(▲展開中, ▼折りたたみ中)
* デフォルト状態: 展開
* 状態保存: `sessionStorage['ksp_mission_list_expanded']`に保存

### 任務カード

#### 任務カード構成

```text
┌─────────────────────────────────┐
│ ☑️ 装備の整理          ⚠️ [×] │
│ Daily                           │
├─────────────────────────────────┤
│ • 小口径主砲 ×2                 │
│ • 12cm単装砲 ×1                 │
└─────────────────────────────────┘
```

#### 任務カード要素

1. **チェックボックス**(左上): 任務の選択/解除
2. **任務名**(上段,太字)
3. **警告アイコン**(右上,条件付き): データ整合性エラー時に表示
4. **削除ボタン**(右上,[×]): ユーザー定義任務のみ表示
5. **周期バッジ**(上段右または下段): Daily, Weekly等
6. **要求装備リスト**(下段): 箇条書き

#### インタラクション

* チェックボックス変更: 即座に廃棄リストを再計算
* カードクリック: 任務編集モーダルを開く(ユーザー定義任務のみ)
* [×]ボタン: 削除確認ダイアログを表示
* 警告アイコンホバー: エラー詳細をツールチップ表示

#### 状態

* 選択中: 背景色を薄い青色にハイライト
* 未選択: 白色背景
* エラーあり: 警告アイコン表示

### フィルタ適用時

* 非表示の任務はDOM上からも削除(パフォーマンス最適化)
* フィルタ解除時に再表示

### 空状態

#### 任務が0件の場合

```text
┌─────────────────────────────────────────────────┐
│                                                 │
│         📋 任務がありません                     │
│         [+ 任務追加] ボタンから追加してください │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 共通仕様

#### 構造

```text
┌───────────────────────────────────────┐
│                                       │
│  ┌─────────────────────────────────┐ │
│  │ モーダルタイトル          [×]  │ │
│  ├─────────────────────────────────┤ │
│  │                                 │ │
│  │ コンテンツエリア                │ │
│  │                                 │ │
│  ├─────────────────────────────────┤ │
│  │          [キャンセル] [保存]   │ │
│  └─────────────────────────────────┘ │
│                                       │

```

#### 要素

* オーバーレイ(背景半透明黒)
* モーダルボックス(中央表示,白背景)
* タイトルバー(上段)
* 閉じるボタン([×],右上)
* コンテンツエリア(中段,スクロール可能)
* ボタンエリア(下段,右寄せ)

#### モーダルの動作

* オーバーレイクリック: モーダルを閉じる
* Escキー: モーダルを閉じる
* 保存ボタン: バリデーションOKなら保存して閉じる
* キャンセルボタン: 変更を破棄して閉じる

### 装備管理モーダル

#### タイトル

`装備の管理・追加`

#### 装備管理モーダルの構成

2セクション構成

#### セクション1: 新規登録フォーム

```text

├─────────────────────────────────────┤
│ [スクロール可能エリア]              │

│ │ 装備名 *                        │  │
│ │ [例: 12.7cm連装砲B型改二]       │  │
│ │                                 │  │
│ │ カテゴリ *                      │  │
│ │ [小口径主砲 ▼]                  │  │
│ │                                 │  │
│ │ 区分 *                          │  │
│ │ [個別装備 (Item) ▼]             │  │
│ │                                 │  │
│ │ [リストに追加]                  │  │
│ └─────────────────────────────────┘  │
│                                     │

│ │ └─────────────────────────┘   │  │
│ └─────────────────────────────────┘  │
└─────────────────────────────────────┘
```

##### セクション1: 新規登録フォーム詳細

* 背景色: 淡いグレー
* タイトル: `📝 新規登録`(Plusアイコン)

###### フィールド

1. **装備名**(テキストボックス)
   * プレースホルダー: `例: 12.7cm連装砲B型改二`
   * 最大40文字
   * 文字数カウンター非表示(シンプル化)
2. **カテゴリ**(テキスト + Datalist)
   * プレースホルダー: `選択または入力`
   * 既存カテゴリをサジェスト
   * 最大20文字
3. **区分**(プルダウン)
   * `個別装備 (Item)`
   * `カテゴリ代表 (「機銃」など)`
4. **追加ボタン**: `リストに追加`(ティール色)

###### 新規登録フォーム動作

* 追加後も入力フィールドをクリア
* モーダルは閉じずに連続追加可能
* 追加後は登録済み一覧に即座に反映

##### セクション2: 登録済み一覧詳細

* タイトル: `📋 登録済み一覧`(件数表示)
* 検索バー: 装備名/カテゴリで絞り込み
* リスト表示:
    * 最大高さ: 約200px(スクロール)
    * 各行: 装備名(太字) + カテゴリ + 区分バッジ + 削除ボタン
    * ホバー時: 背景色変化 + 削除ボタン表示
* 公式マスタ: 削除不可(「公式」ラベル表示)
* ユーザー定義: 削除可能(ゴミ箱アイコン)

#### バリデーション

* リアルタイムバリデーション
* 必須フィールド未入力時は追加ボタンを無効化
* 同名警告は表示するが追加は可能

#### モーダル閉じる動作

* [×]ボタン: モーダルを閉じる
* オーバーレイクリック: モーダルを閉じる
* Escキー: モーダルを閉じる
* キャンセルボタン: なし(常時開いたまま操作可能)

### 任務追加/編集モーダル

#### 任務追加/編集モーダルのタイトル

* 追加時: `任務を追加`
* 編集時: `任務を編集`

#### フォーム

```text
┌─────────────────────────────────────┐
│ 任務を追加                    [×]   │
├─────────────────────────────────────┤
│                                     │
│ 任務名 *                            │
│ [例: (単) 新型兵装の廃棄]           │
│                                     │
│ 周期 *                              │
│ [Weekly ▼]                          │
│                                     │
│ ┌─ 要求装備 (最大10枠) ─────────┐ │
│ │ [機銃 - 7.7mm機銃 ▼]  [3]      │ │
│ │ [小口径主砲 - 12cm砲 ▼] [2] [×]│ │
│ │                    [+ 装備追加] │ │
│ └─────────────────────────────────┘ │
│                                     │
├─────────────────────────────────────┤
│          [キャンセル] [追加]       │
└─────────────────────────────────────┘
```

#### 注意

* 要求装備は1枠以上必須（最初の1枠は削除不可）
* 最大10枠まで追加可能
* 動的に行追加/削除が可能

##### 任務追加/編集フィールド

1. **任務名**(テキストボックス)
   * プレースホルダー: `例: 装備の整理`
   * 最大50文字
   * 文字数カウンター表示
2. **周期**(プルダウン)
   * `Daily`, `Weekly`, `Monthly`, `Quarterly`, `Yearly`, `OneTime`
3. **要求装備リスト**(動的リスト)
   * 各行に装備選択プルダウン + 必要数スピンボタン + 削除ボタン
   * [+ 装備を追加]ボタンで行を追加
   * 最大10件まで

##### 要求装備の行

```text
┌───────────────────────────────────────────┐
│ [12cm単装砲 ▼]  [2 ▲▼]        [削除]    │
└───────────────────────────────────────────┘
```

* 装備選択プルダウン: 全装備リストから選択
* 必要数スピンボタン: 1〜30の整数
* 削除ボタン: その行を削除

##### 任務追加/編集バリデーション

* 要求装備が0件の場合は保存不可
* 要求装備が10件を超えた場合は[+ 装備を追加]ボタンを無効化
* 同じ装備を複数回選択している場合はエラー表示
