# UI仕様書

## 概要

本文書では,艦これ工廠任務廃棄マネージャーのユーザーインターフェースの詳細仕様を定義する.

## 全体レイアウト

### 画面構成

任務を選ぶ操作領域と,選択結果を示す結果パネルを別ペインに置く.結果パネルは選択操作を覆わない.

```text
┌───────────────────────────────────────────────────────────┐
│ Header                                                    │
├───────────────────────────────────────────────────────────┤
│ Global Warning Banner (条件付き表示)                     │
├──────────────────────────────┬────────────────────────────┤
│ Control Bar                  │ 結果パネル (固定表示)      │
│ [フィルタ] [装備管理] [任務] │ ┌────────────────────────┐ │
├──────────────────────────────┤ │ 廃棄リスト             │ │
│ Mission List (スクロール)    │ ├────────────────────────┤ │
│ ┌──────────────────────────┐ │ │ ベース任務の達成状況   │ │
│ │ 任務1                    │ │ ├────────────────────────┤ │
│ ├──────────────────────────┤ │ │ 選択中の任務           │ │
│ │ 任務2                    │ │ └────────────────────────┘ │
│ └──────────────────────────┘ │                            │
└──────────────────────────────┴────────────────────────────┘
```

### レスポンシブ対応

| ブレークポイント | 画面幅      | レイアウト                                             |
| :--------------- | :---------- | :----------------------------------------------------- |
| Desktop          | 1024px以上  | 2ペイン.結果パネルを右カラムに固定表示                 |
| Tablet           | 640〜1023px | 1カラム.結果パネルを画面上部に固定表示,廃棄リストは2列 |
| Mobile           | 639px以下   | 1カラム.結果パネルを画面上部に固定表示,廃棄リストは1列 |

結果パネルには高さ上限を設ける.上限を超える内容はパネル内スクロールで扱い,任務リストの表示領域を侵食しない.

| 配置         | 高さ上限              |
| :----------- | :-------------------- |
| 右カラム固定 | ビューポート高 - 2rem |
| 画面上部固定 | ビューポート高の45%   |

```text
┌────────────────────────────────────────────┐
│ 🔧 艦これ 工廠任務廃棄プランナー    [≡]   │
└────────────────────────────────────────────┘
```

- アプリ名(左寄せ)
- 設定メニューボタン(右寄せ,ハンバーガーアイコン)

### 設定メニュー

#### トリガー

[≡]ボタンクリック

#### 表示方法

ドロップダウンメニュー(右上から展開)

#### メニュー項目

```text
┌──────────────────────┐
│ 📤 装備をエクスポート │
│ 📤 任務をエクスポート │
│ 📥 データをインポート │
├──────────────────────┤
│ ℹ️ About             │
└──────────────────────┘
```

- About: アプリ情報モーダルを開く

## Global Warning Banner

### 位置

Headerの直下,2ペイン領域の上

### 表示条件

- ネットワークエラー発生時
- データ更新通知時
- LocalStorageデータ破損検出時（起動時バリデーション）
- 重大なバリデーションエラー時

- Warning: 黄色背景,黒文字,⚠️アイコン
- Error: 赤色背景,白文字,❌アイコン
- Info: 青色背景,白文字,ℹ️アイコン

#### 構成

```text
┌─────────────────────────────────────────────────┐
│ ⚠️ メッセージ内容                [再試行] [×] │
└─────────────────────────────────────────────────┘
```

- アイコン(左)
- メッセージテキスト(中央)
- アクションボタン(右,オプション)
- 閉じるボタン(右端)

## 結果パネル

選択中の任務から導かれる情報を1つのパネルにまとめる.パネルは3つのセクションを縦に並べ,各セクションはタイトルバークリックで個別に開閉する.デフォルトはいずれも展開.

| セクション           | 内容                                     | 表示条件           |
| :------------------- | :--------------------------------------- | :----------------- |
| 廃棄リスト           | 選択任務全体から算出した廃棄装備と必要数 | 常時               |
| ベース任務の達成状況 | ベース任務の要求に対する過不足           | ベース任務の設定時 |
| 選択中の任務         | 選択済み任務の一覧とベース任務の切り替え | 1件以上選択時      |

### 廃棄リスト

#### タイトルバー

```text
┌──────────────────────────────────┐
│ 🗑️ 廃棄リスト  計 43      [▲/▼] │
└──────────────────────────────────┘
```

- 左: アイコン + タイトル + 全カテゴリの合計数バッジ
- 右端: 開閉アイコン(▲展開中, ▼折りたたみ中)

#### 任務未選択時

```text
┌──────────────────────────────────┐
│  任務一覧から任務を選択してください │
└──────────────────────────────────┘
```

#### 廃棄リスト表示時

カテゴリごとに1グループを縦に並べる.

```text
┌──────────────────────────────────┐
│ 機銃                        計 6 │
│   7.7mm機銃                    2 │
│   種別不問                     4 │
├──────────────────────────────────┤
│ 小口径主砲     [種別不問]      3 │
├──────────────────────────────────┤
│ 艦上戦闘機     [種別不問]      6 │
└──────────────────────────────────┘
```

グループは2つの形をとる.

- 個別装備を含むグループ: 見出し行にカテゴリ名と合計数,内訳行に個別装備の必要数とカテゴリ残数(「種別不問」)を置く
- カテゴリ要求だけのグループ: 合計と内訳が同値になるため,カテゴリ名・「種別不問」タグ・必要数を1行にまとめる

数値は右端に揃え,等幅数字で表示する.

#### カラム数

| 画面幅      | カラム数 |
| :---------- | :------- |
| 1024px以上  | 1        |
| 640〜1023px | 2        |
| 639px以下   | 1        |

#### ソート

カテゴリ名の日本語ロケール順

### ベース任務の達成状況

ベース任務の要求数に対し,補助任務の廃棄で満たされる数との差分を装備・カテゴリごとに示す.

```text
┌──────────────────────────────────┐
│ ⚠️ ベース任務の達成状況 [不足 3] │
├──────────────────────────────────┤
│ ↘ 中口径主砲（種別不問）  不足 -3 │
│    ベース 3・補助 0              │
│ ↗ 魚雷（種別不問）        余剰 +3 │
│    ベース 0・補助 3              │
├──────────────────────────────────┤
│ 全12種類  不足: 3種  ベース不要: 9種 │
└──────────────────────────────────┘
```

- タイトルバー: 不足がある場合に不足種類数のバッジを表示
- 各行の1段目: 状態アイコン,対象名,不足/余剰の差分
- 各行の2段目: ベース任務の要求数と補助任務による充足数
- 末尾: 全体の種類数と状態別の内訳

状態アイコンと配色は差分の種類に対応する.

| 状態             | アイコン | 配色   |
| :--------------- | :------- | :----- |
| 不足             | 下向き   | 赤     |
| 過不足なし       | チェック | 緑     |
| 余剰             | 上向き   | 青     |
| ベース任務が不要 | 上向き   | グレー |

### 選択中の任務

選択済み任務を1行1件で縦に並べる.

```text
┌──────────────────────────────────────────┐
│ ✓ 選択中の任務  3/8               [▲/▼] │
├──────────────────────────────────────────┤
│ ◎ ベース = 達成状況の比較基準にする任務  │
│ ┃[◎ベース] 装備開発力の集中整備  Weekly  │
│ ┃          [ベース解除] [×]              │
│ ┃ 中口径主砲（種別不問）×3, ...          │
│   装備開発力の整備  Daily                │
│              [ベースに設定] [×]          │
│   小口径主砲（種別不問）×4               │
├──────────────────────────────────────────┤
│        [× すべての選択を解除]            │
└──────────────────────────────────────────┘
```

#### 行の構成

- 1段目: ベースバッジ(ベース任務のみ),任務名,周期バッジ,ベース切り替えボタン,選択解除ボタン
- 2段目: 要求装備の要約(1行に収まらない場合は省略記号で切り,ツールチップに全文)

#### ベース任務の識別

ベース任務は3つの手掛かりで示す.

- 行の背景を淡い橙,左端に橙の縦罫線
- 任務名の前に「◎ ベース」バッジ
- 切り替えボタンのラベルが「ベース解除」(未設定の行は「ベースに設定」)

リスト先頭に凡例を置き,ベース任務が達成状況の比較基準であることと,設定できるのが1件であることを示す.

任務リスト側の任務カードでも,ベース任務には同じ「◎ ベース」バッジを任務名の前に表示する.

#### 一括解除

「すべての選択を解除」はリスト末尾に全幅の低優先度ボタンとして置く.行ごとの操作および開閉アイコンと干渉しない位置とする.

## Control Bar

### Control Barの位置

任務ペインの最上部,Mission Listの上

### Control Barの構成

```text
┌────────────────────────────────────────────────────────────────────────────────┐
│ 🔍 [任務名検索...] [周期 ▼] [装備カテゴリ ▼]  [+ 装備管理] [+ 任務追加] │
└────────────────────────────────────────────────────────────────────────────────┘
```

### フィルタ

フィルタは組み合わせて使用可能(AND条件):

- テキスト検索 AND 周期 AND 装備カテゴリ
- 例: 「Weekly」かつ「機銃」を要求する任務のみ表示

#### フィルタ詳細

##### テキスト検索

- 入力フィールド: 任務名で部分一致検索
- プレースホルダー: `任務名を検索...`
- リアルタイム検索(デバウンス300ms)
- 左側に虫眼鏡アイコン

##### 周期フィルタ

###### 周期フィルタのトリガー

[周期 ▼]プルダウン選択

###### 周期フィルタの表示方法

ドロップダウン選択

###### 周期フィルタ項目

```text
┌────────────────────┐
│ 全て              │
│ Daily            │
│ Weekly           │
│ Monthly          │
│ Quarterly        │
│ Yearly           │
│ OneTime          │
└────────────────────┘
```

- デフォルト: `全て`
- 単一選択(ドロップダウン)
- 選択時: その周期の任務のみ表示
- SessionStorageに保存: `ksp_filter_period`

##### 装備カテゴリフィルタ

###### 装備カテゴリフィルタのトリガー

[装備カテゴリ ▼]プルダウン選択

###### 装備カテゴリフィルタの表示方法

ドロップダウン選択

###### フィルタ項目

```text
┌────────────────────┐
│ 全種別             │
│ 小口径主砲         │
│ 機銃               │
│ 魚雷               │
│ ...                │
└────────────────────┘
```

- デフォルト: `全種別`
- 動的生成: 装備マスタから一意なカテゴリを抽出
- 単一選択(ドロップダウン)
- 選択時: そのカテゴリを要求する任務のみ表示
- SessionStorageに保存: `ksp_filter_category`

##### フィルタの組み合わせ

###### AND条件

- テキスト検索 AND 周期フィルタ AND 装備カテゴリフィルタ
- 例1: テキスト「装備」+ 周期「Weekly」→ 任務名に「装備」を含むWeekly任務のみ
- 例2: 周期「Weekly」+ 装備「機銃」→ 機銃を要求するWeekly任務のみ
- 例3: 全てのフィルタを組み合わせ可能

###### OR条件

- 初期リリースでは未対応
- 将来的にチェックボックス形式で複数選択(OR条件)を検討

## Mission List

### Mission Listの位置

Control Barの下,画面中央メインエリア

### レイアウト

グリッドまたはリスト形式

### 任務一覧の開閉機能

任務一覧が長くなった場合にエラーログなど下部コンテンツへのアクセスを容易にするため,任務一覧エリア全体を折りたたみ可能にする.

#### トグル動作

- タイトルバーまたは専用ボタンをクリックで展開/折りたたみ
- 折りたたみ時: 任務カードを非表示にし,タイトルバーのみ表示
- 展開時: すべての任務カードを表示(デフォルト状態)

#### UI表示

```text
展開時:
┌─────────────────────────────────────────────────┐
│ 📋 任務一覧 (15件)                     [▲]     │
├─────────────────────────────────────────────────┤
│ [任務カード1]                                   │
│ [任務カード2]                                   │
│ ...                                             │
└─────────────────────────────────────────────────┘

折りたたみ時:
┌─────────────────────────────────────────────────┐
│ 📋 任務一覧 (15件)                     [▼]     │
└─────────────────────────────────────────────────┘
```

- タイトルバー左: アイコン + 「任務一覧」+ 件数表示
- タイトルバー右: 開閉アイコン(▲展開中, ▼折りたたみ中)
- デフォルト状態: 展開
- 状態保存: `sessionStorage['ksp_mission_list_expanded']`に保存

### 任務カード

#### 任務カード構成

```text
┌─────────────────────────────────┐
│ ☑️ 装備の整理          ⚠️ [×] │
│ Daily                           │
├─────────────────────────────────┤
│ • 小口径主砲 ×2                 │
│ • 12cm単装砲 ×1                 │
└─────────────────────────────────┘
```

#### 任務カード要素

1. **チェックボックス**(左上): 任務の選択/解除
1. **任務名**(上段,太字)
1. **警告アイコン**(右上,条件付き): データ整合性エラー時に表示
1. **削除ボタン**(右上,[×]): ユーザー定義任務のみ表示
1. **周期バッジ**(上段右または下段): Daily, Weekly等
1. **要求装備リスト**(下段): 箇条書き

#### インタラクション

- チェックボックス変更: 即座に廃棄リストを再計算
- カードクリック: 任務編集モーダルを開く(ユーザー定義任務のみ)
- [×]ボタン: 削除確認ダイアログを表示
- 警告アイコンホバー: エラー詳細をツールチップ表示

#### 状態

- 選択中: 背景色を薄い青色にハイライト
- 未選択: 白色背景
- エラーあり: 警告アイコン表示

### フィルタ適用時

- 非表示の任務はDOM上からも削除(パフォーマンス最適化)
- フィルタ解除時に再表示

### 空状態

#### 任務が0件の場合

```text
┌─────────────────────────────────────────────────┐
│                                                 │
│         📋 任務がありません                     │
│         [+ 任務追加] ボタンから追加してください │
│                                                 │
└─────────────────────────────────────────────────┘
```

## エラー・警告表示

エラーや警告はGlobal Warning Bannerに集約表示する. 旧設計のFooter Areaエラーログは廃止済み.

詳細は `docs/error_handling.md` を参照.

## モーダル

### 共通仕様

#### 構造

```text
┌───────────────────────────────────────┐
│                                       │
│  ┌─────────────────────────────────┐ │
│  │ モーダルタイトル          [×]  │ │
│  ├─────────────────────────────────┤ │
│  │                                 │ │
│  │ コンテンツエリア                │ │
│  │                                 │ │
│  ├─────────────────────────────────┤ │
│  │          [キャンセル] [保存]   │ │
│  └─────────────────────────────────┘ │
│                                       │
└───────────────────────────────────────┘
```

#### 要素

- オーバーレイ(背景半透明黒)
- モーダルボックス(中央表示,白背景)
- タイトルバー(上段)
- 閉じるボタン([×],右上)
- コンテンツエリア(中段,スクロール可能)
- ボタンエリア(下段,右寄せ)

#### モーダルの動作

- オーバーレイクリック: モーダルを閉じる
- Escキー: モーダルを閉じる
- 保存ボタン: バリデーションOKなら保存して閉じる
- キャンセルボタン: 変更を破棄して閉じる

#### タイトル

`装備の管理・追加`

#### 装備管理モーダルの構成

2セクション構成

#### セクション1: 新規登録フォーム

```text
┌─────────────────────────────────────┐
│ 装備の管理・追加              [×]   │
├─────────────────────────────────────┤
│ [スクロール可能エリア]              │
│                                     │
│ ┌─ 新規登録 ────────────────────┐  │
```

##### セクション1: 新規登録フォーム詳細

- 背景色: 淡いグレー
- タイトル: `📝 新規登録`(Plusアイコン)

###### フィールド

1. **装備名**(テキストボックス)
    - プレースホルダー: `例: 12.7cm連装砲B型改二`
    - 最大40文字
    - 文字数カウンター非表示(シンプル化)
1. **カテゴリ**(テキスト + Datalist)
    - プレースホルダー: `選択または入力`
    - 既存カテゴリをサジェスト
    - 最大20文字
1. **追加ボタン**: `リストに追加`(ティール色)

###### 新規登録フォーム動作

- 追加後も入力フィールドをクリア
- モーダルは閉じずに連続追加可能
- 追加後は登録済み一覧に即座に反映

##### セクション2: 登録済み一覧詳細

- タイトル: `📋 登録済み一覧`(件数表示)
- 検索バー: 装備名/カテゴリで絞り込み
- リスト表示:
    - 最大高さ: 約200px(スクロール)
    - 各行: 装備名(太字) + カテゴリ + 削除ボタン
    - ホバー時: 背景色変化 + 削除ボタン表示
- マスタデータ: 削除不可(タグ表示なし)
- ユーザー定義: 削除可能(ゴミ箱アイコン, 「ユーザー」ラベル表示)

#### バリデーション

- リアルタイムバリデーション
- 必須フィールド未入力時は追加ボタンを無効化
- 同名警告は表示するが追加は可能

#### モーダル閉じる動作

- [×]ボタン: モーダルを閉じる
- オーバーレイクリック: モーダルを閉じる
- Escキー: モーダルを閉じる
- キャンセルボタン: なし(常時開いたまま操作可能)

### 任務追加/編集モーダル

#### 任務追加/編集モーダルのタイトル

- 追加時: `任務を追加`
- 編集時: `任務を編集`

#### フォーム

```text
┌─────────────────────────────────────┐
│ 任務を追加                    [×]   │
├─────────────────────────────────────┤
│                                     │
│ 任務名 *                            │
│ [例: (単) 新型兵装の廃棄]           │
│                                     │
│ 周期 *                              │
│ [Weekly ▼]                          │
│                                     │
│ ┌─ 要求装備 (最大10枠) ─────────┐ │
│ │ [機銃 - 7.7mm機銃 ▼]  [3]      │ │
│ │ [小口径主砲 - 12cm砲 ▼] [2] [×]│ │
│ │                    [+ 装備追加] │ │
│ └─────────────────────────────────┘ │
│                                     │
├─────────────────────────────────────┤
│          [キャンセル] [追加]       │
└─────────────────────────────────────┘
```

#### 注意

- 要求装備は1枠以上必須（最初の1枠は削除不可）
- 最大10枠まで追加可能
- 動的に行追加/削除が可能

##### 任務追加/編集フィールド

1. **任務名**(テキストボックス)
    - プレースホルダー: `例: 装備の整理`
    - 最大50文字
    - 文字数カウンター表示
1. **周期**(プルダウン)
    - `Daily`, `Weekly`, `Monthly`, `Quarterly`, `Yearly`, `OneTime`
1. **要求装備リスト**(動的リスト)
    - 各行に装備選択プルダウン + 必要数スピンボタン + 削除ボタン
    - [+ 装備を追加]ボタンで行を追加
    - 最大10件まで

##### 要求装備の行

```text
┌───────────────────────────────────────────┐
│ [12cm単装砲 ▼]  [2 ▲▼]        [削除]    │
└───────────────────────────────────────────┘
```

- 装備選択プルダウン: 全装備リストから選択
- 必要数スピンボタン: 1〜30の整数
- 削除ボタン: その行を削除

##### 任務追加/編集バリデーション

- 要求装備が0件の場合は保存不可
- 要求装備が10件を超えた場合は[+ 装備を追加]ボタンを無効化
- 同じ装備を複数回選択している場合はエラー表示
