# リリース前動作確認メモ

v1.0.0リリース前に確認すべき主要な動作ポイント.

## 基本動作確認

### 初回起動
* Aboutモーダルが自動表示される
* マスタデータがGitHub Pagesからフェッチされる
* フェッチ失敗時にローカルファイルへフォールバックする

### データ管理
* 装備の追加・削除が正常に動作する
* 任務の追加・編集・削除が正常に動作する
* LocalStorageにデータが保存される
* ページリロード後もデータが保持される

### コア機能
* 任務選択（最大8件）が動作する
* 廃棄リスト計算が正しく動作する
  * MAX集計（同じ装備の最大値採用）
  * 包含関係解決（ItemとCategoryのOR条件）
* フィルタ機能（テキスト検索・周期・カテゴリ）が動作する

### エラー処理
* バリデーションエラーが正しく表示される
  * 必須フィールド空白時
  * 文字数超過時
  * XSS検出時
* Global Warning Bannerが適切に表示される
  * マスタフェッチ失敗時
  * LocalStorage破損データ削除時

## ブラウザ動作確認

最低限以下で動作確認する:
* Chrome最新版
* Firefox最新版 または Safari最新版

## デプロイ前最終確認

* [ ] `npm run build`が正常に完了する
* [ ] `dist/`フォルダに`data/*.json`が含まれている
* [ ] ビルド後の`dist/index.html`をローカルで開いて動作確認
* [ ] GitHub Pagesの`public/data/*.json`が最新版である
* [ ] `package.json`のバージョンが更新されている

## 既知の制限事項

リリース時点で未実装の機能（v1.1.0以降対応予定）:
* インポート/エクスポート機能
* ネットワークリトライ・タイムアウト
* プライベートモード検出
* storage監視（他タブ更新検知）
* LocalStorage容量警告
* フィルタ永続化
