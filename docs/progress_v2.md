# v2.0.0 ロードマップ

## リリース戦略

```
v1.0.0-beta
  ↓
Phase 1-3: コア機能実装 ── 完了
  ↓
Phase 4A: 破壊的変更（alpha前）── 完了
  ↓
v2.0.0-alpha ── リリース済み
  ↓
Phase 4B: リファクタ（alpha後）── ほぼ完了（残り #119, #157）
  ↓
v2.0.0-beta
  ↓
#142: マスタデータ拡充
  ↓
v2.0.0 正式版
```

**alpha前後の区分**:

* **alpha前（Phase 4A）**: ユーザーデータに影響する破壊的変更（バリデーション厳格化, データ初期化機能）
* **alpha後（Phase 4B）**: 動作変更なしのリファクタリング（ユーザーへの影響なし）
