# 艦これ 工廠任務廃棄マネージャー

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

**[艦これ 工廠任務廃棄マネージャー](https://app.sk44.jp/kancolle-scrap-manager/)**

艦これで複数の廃棄任務を並列で遂行する際に、廃棄すべき装備のリストを自動計算するWebアプリケーション.

**注意**: 本アプリはAI（Claude Code）を利用して開発されました. ドキュメントもAIにより生成されています.

## 特徴

* 廃棄リストを自動計算
* すべてのデータはブラウザ内に保存（サーバーにデータは送信されません）
* 独自の装備・任務を追加・管理できます
* **v2.0.0-beta 新機能**:
  * ベース任務/副任務の概念導入
  * データ初期化機能（設定メニューから全データを削除可能）
  * 任務の編集機能

## 使い方

### 基本操作

1. **任務を選択する**
   * 画面に表示されている任務カードのチェックボックスをクリック
   * 最大8件まで同時選択可能

2. **廃棄リストを確認する**
   * 画面上部の「廃棄リスト」に必要な装備と個数が自動表示されます
   * 同じ装備を複数の任務で要求する場合、最大値を採用します

3. **任務を解除する**
   * 「選択中の任務」セクションの[×]ボタンで個別解除
   * 「すべて解除」ボタンで全選択解除

### フィルタ機能

Control Barから任務を絞り込めます:

* **テキスト検索**: 任務名で部分一致検索
* **周期フィルタ**: Daily / Weekly / Monthly / Quarterly / Yearly / OneTime
* **カテゴリフィルタ**: 装備カテゴリ（小口径主砲、機銃など）で絞り込み

### 装備・任務の管理

* **装備管理**: Control Barの「装備管理」ボタンから独自の装備を追加・削除・並び替え
* **任務追加**: Control Barの「任務追加」ボタンから独自任務を作成
* **編集・削除**: 各カードの鉛筆アイコン（編集）、ゴミ箱アイコン（削除）

## 計算ロジックの例

ケース1: 包含関係の自動調整

* 任務A「機銃 ×5」+ 任務B「25mm単装機銃 ×2」
* → 結果「25mm単装機銃 ×2, 機銃 ×3」
* （25mm単装機銃は機銃カテゴリに含まれるため、重複分が自動調整されます）

ケース2: MAX集計

* 任務A「小口径主砲 ×3」+ 任務B「小口径主砲 ×5」
* → 結果「小口径主砲 ×5」
* （合計ではなく、最大値を採用します）

詳細は `docs/calculation_logic.md` を参照.

## よくある質問（FAQ）

### Q1. データはどこに保存されますか？

すべてのデータはブラウザ内（LocalStorage）に保存されます. サーバーには送信されません.

### Q2. 他のブラウザやデバイスでデータを共有できますか？

現在は非対応です. 将来的にエクスポート/インポート機能を実装予定です.

### Q3. マスタデータが読み込めない警告が表示されました

アプリに同梱されたバックアップデータが自動で使用されます. 通常は問題なく動作します.

### Q4. ブラウザを変えたらデータが消えました

LocalStorageはブラウザごとに独立しています. 将来的なエクスポート/インポート機能で対応予定です.

## トラブルシューティング

### データが破損している

画面上部に「破損したデータを削除しました」という警告が表示された場合:

* 破損したデータは自動で削除されます
* 警告バナーの[×]ボタンで非表示にできます

### 装備や任務を保存できない

保存できない場合は以下を確認してください:

* 必須フィールドが空白になっていないか
* 文字数制限を超えていないか（装備名40文字、任務名50文字、カテゴリ20文字）
* HTMLタグやスクリプトを含んでいないか（セキュリティ上禁止）

### LocalStorage容量不足

「データを保存できませんでした」というエラーが表示された場合:

* 不要なユーザー定義装備・任務を削除してください

### データを初期化したい

v2.0.0-betaから追加された機能で、全データを削除して初期状態に戻すことができます:

1. ヘッダーの設定アイコン（⚙️）をクリック
2. 「⚠️ データを初期化（全削除）」を選択
3. 確認ダイアログで「初期化」をクリック

**注意**: この操作は取り消せません。実行前に必ずバックアップを取ってください。

### それでも解決しない場合

[GitHubリポジトリのIssue](https://github.com/sakashita44/kancolle-scrap-manager/issues)にバグ報告をお願いします.
